# botini — быстрый старт

Умный мульти-пара грид-бот. Сначала **анализирует** пары на истории и
торгует только подходящие, ведёт несколько пар сразу, делит бюджет,
показывает всё в **одном терминале** и держит **портфельный стоп**.

Режим по умолчанию: **TESTNET, 1000 USDT, 3 лучшие пары, ордер ≥ 5 USDT.**
Параметры — вверху файла `botini.py` (блок «НАСТРОЙКИ»).

## Termux (телефон)

```bash
# 1) распаковать в Загрузки (папка будет называться botini)
pkg install -y unzip python
cd ~/storage/downloads/botini        # или туда, куда распаковал

# 2) зависимости
pip install -r requirements.txt

# 3) ключи Bybit (только Spot Trade, без Withdraw)
cp bot/.env.example bot/.env
nano bot/.env                        # вписать BYBIT_API_KEY и BYBIT_API_SECRET

# 4) запуск
python botini.py                     # с анализом (займёт ~минуту)
# или быстрый старт без анализа:
python botini.py --skip-analysis
```

Наблюдение:
- **Терминал** — живой поток, каждая строка помечена парой: `[BTCUSDT] …`,
  подключение 🟢/🔴, свеча 🕯 O/H/L/C, покупки/продажи, портфель 📦.
- **Панель** в браузере телефона: `http://localhost:8899` (BTC),
  `http://localhost:8900` (ETH), `8901` (SOL) — по одной на пару.

Остановка: `Ctrl+C` — отменит ордера и сохранит состояние (в папке `run/`).
При следующем запуске состояние подхватится.

## ПК (Linux / Mac)

```bash
pip install -r requirements.txt
cp bot/.env.example bot/.env      # вписать ключи
python botini.py
```

## Честно
- Это **не гарантия прибыли**. Грид зарабатывает в боковике и теряет на
  затяжном падении; анализ и портфельный стоп ограничивают риск, но не
  отменяют убыток.
- Начинай на **testnet** (стоит по умолчанию). На реальные деньги —
  только после того, как своими глазами увидел, как бот себя ведёт.
- Один аккаунт Bybit = один общий баланс на все пары. Портфельный стоп
  в botini считает просадку по всему депозиту.
