# Bybit Grid Bot v2 — подробная инструкция

Автономный сеточный бот для спота Bybit: сам перестраивает сетку, сам
останавливается при просадке, сам пересиживает шторм, показывает всё живьём
в консоли (Termux) и на панели localhost, переживает перезагрузку.

Честная рамка: это автоматизация, а не источник гарантированного дохода.
Грид зарабатывает понемногу в боковике и теряет при затяжном падении —
защиты ограничивают убыток, но не отменяют его. Торгуй суммой, потеря
которой не изменит твою жизнь.

---

## Шаг 0. Установи Python (если нет)

Windows: скачай с python.org (версия 3.10+), при установке ОБЯЗАТЕЛЬНО
поставь галочку «Add Python to PATH».
Проверка — открой командную строку (Win+R → cmd) и введи:
```
python --version
```
Должно показать версию. Если «не является командой» — переустанови с галочкой.

## Шаг 1. Установи зависимости

В командной строке зайди в папку бота и выполни:
```
cd путь\к\папке\bybit-grid-bot-v2
pip install -r requirements.txt
```

## Шаг 2. Получи ключи Bybit (сначала TESTNET)

1. Зайди на **testnet.bybit.com** и зарегистрируйся (отдельный аккаунт,
   не связан с основным Bybit).
2. Пополни виртуальный баланс: в кошельке есть кнопка запроса тестовых
   монет (Faucet / Request coins). Возьми USDT.
3. Профиль → **API** → Create New Key → System-generated.
4. Права: включи только **Read** и **Spot Trade**. Withdraw НЕ включай никогда.
5. Скопируй API Key и Secret — секрет показывается один раз.

## Шаг 3. Наблюдение (Telegram больше не нужен)

Всё видно двумя способами, без внешних сервисов:
- **Консоль / Termux** — живой поток: 🟢/🔴 подключение, ⏱ пульс
  (цена / ордера / профит), 🕯 свежая свеча O/H/L/C, каждая покупка и
  продажа, тревоги. Плюс всё пишется в файл `bot.log`.
- **Панель localhost:8899** — лестница сетки, цена, профит, лента событий,
  кнопка стопа.

## Шаг 4. Заполни .env

Скопируй файл `.env.example` в `.env` (просто копия с новым именем):
```
copy .env.example .env        (Windows)
cp .env.example .env          (Linux/Mac)
```
Открой `.env` и вставь 2 значения из шага 2 — ключ и секрет Bybit.

## Шаг 5. Проверь config.yaml

| Параметр | Что значит | Разумный старт |
|---|---|---|
| testnet | Виртуальные деньги | true (не трогай!) |
| symbol | Пара | BTCUSDT |
| budget_usdt | Потолок трат бота | 500 (на тестнете) |
| grid_range_pct | Ширина сетки ±% | 5 |
| grid_levels | Уровней покупки | 10 |
| rebuild_on_breakout_up | Догонять цену вверх | true |
| stop_loss_extra_pct | Стоп ниже сетки, % | 3 |
| stop_action | После стопа: stop/rebuild | stop |
| max_drawdown_pct | Лимит просадки депозита | 15 |
| volatility_max_pct | Порог шторма | 1.2 |
| report_hour | Час дневного отчёта | 21 |

## Шаг 6. Запуск

Обычный запуск:
```
python bot.py
```
Запуск с watchdog (авторестарт при падении) — рекомендую:
```
run.bat          (Windows — двойной клик)
./run.sh         (Linux/Mac)
```
В консоли появится «🤖 Grid Bot запущен» и построенная сетка.

Остановка: Ctrl+C → бот спросит, отменить ли ордера.
- y — отменит всё (чисто выключиться надолго)
- Enter — оставит ордера на бирже (перезапустишь — бот их подхватит)

## Автозапуск при включении ПК (Windows)

1. Win+R → `shell:startup` → Enter
2. Скопируй туда ярлык на `run.bat`
Теперь бот стартует вместе с Windows и восстанавливает ордера из state.json.

## Веб-панель (визуальный контроль)

После запуска бота открой в браузере: **http://localhost:8899**

Там живьём: «лестница» сетки с уровнями, зелёные точки — ордера на покупку,
красные — на продажу, золотая линия — текущая цена, ползающая между ними.
Плюс график профита за сессию, лента событий и кнопка «⏹ Остановить бота»
(отменяет все ордера, с подтверждением).

Панель видна только с этого компьютера (слушает 127.0.0.1) — из интернета
к ней не подключиться. Порт меняется в config.yaml (web_port). Обновляется
сама каждые 3 секунды.

Консоль/файл `bot.log`:
```
>>> КУПЛЕНО L3 @ 61200 -> продажа @ 61850
>>> ПРОДАНО L4 @ 61850 | +0.53 USDT | всего +4.12 (8 сделок)
⏱ цена 61850 | ордеров 9 | профит +4.1200 USDT | 🟢 связь
🕯 свеча 5м  O:61810  H:61900  L:61790  C:61850  🟩 рост
```
Там же: 🟢/🔴 подключение и потеря связи, тревоги (🛑 стоп, 🌪 шторм,
🚀 пробой вверх), дневной отчёт 📈 и «♻️ восстановлено» после перезапусков.
Если установлен Termux:API — важные события дублируются в шторку телефона.

## Что бот решает сам, а что — ты

Сам: перестройка сетки вверх, пауза в шторм, распродажа при стопе и
просадке, восстановление после сбоев.
Ты: запуск после срабатывания лимита просадки (это осознанно — если
депозит просел на 15%, машина не должна решать за тебя, продолжать ли).

## Переход на реальные деньги — чек-лист

- [ ] 7+ дней на testnet: бот пережил перезапуски, стопы, перестройки
- [ ] Ты видел в консоли все типы сообщений и понимаешь их
- [ ] Понимаешь каждый параметр config.yaml
- [ ] Боевой ключ создан БЕЗ права Withdraw
- [ ] budget_usdt на старте — небольшой (например 100–200 USDT)
- [ ] testnet: false — и первые дни поглядывай чаще

## Частые проблемы

**«Нет ключей Bybit»** — не создан .env или он пустой (шаг 4).
**retCode=10003/10004** — неверный ключ/секрет или ключ от testnet при
testnet:false (и наоборот).
**«Ни одного ордера»** — budget_usdt слишком мал: на уровень выходит
меньше минимума биржи (~1–5 USDT). Увеличь бюджет или уменьши grid_levels.
**Бот «ничего не делает»** — это нормально: сетка ждёт движения цены.
На testnet ликвидность странная, сделки могут быть редкими.
