# GridLab — бэктестер сеточной стратегии

Отвечает на главный вопрос до того, как ты рискнёшь деньгами:
**«А сколько бы этот бот заработал или потерял на самом деле?»**

Скачивает реальную историю цен с Bybit (публичное API, ключи не нужны),
прогоняет через неё сеточную стратегию из bybit-grid-bot-v2 — с комиссиями
0.1%, стоп-лоссами и перестройками — и выдаёт отчёт с графиком.

## Установка
```bash
pip install -r requirements.txt
```

## Быстрый старт
```bash
# Как повела бы себя наша сетка на BTC за последние 90 дней?
python backtest.py --symbol BTCUSDT --days 90

# Другие параметры сетки
python backtest.py --symbol ETHUSDT --days 180 --range 7 --levels 15 --budget 1000

# Перебор 16 комбинаций параметров — какая сетка была лучшей?
python backtest.py --symbol BTCUSDT --days 90 --sweep
```

## Что в отчёте
- Чистый результат в USDT и % (после комиссий, с учётом остатка монеты)
- Сравнение с «просто купить и держать» — обязательный тест на честность:
  если сетка проигрывает холду, бот не нужен
- Максимальная просадка — сколько нервов это стоило бы по пути
- Число сделок, перестроек, срабатываний стопа
- График equity_curve.png: стратегия против холда

## Как этим пользоваться по уму
1. Прогони одни и те же параметры на **разных отрезках**: --days 30, 90, 180.
   Хорошие параметры — те, что не сливают ни на одном, а не чемпион одного.
2. Прогони на **разных монетах** — BTC, ETH и что собираешься торговать.
3. Найденные параметры перенеси в config.yaml бота → неделя testnet → решение.

## Пределы честности бэктеста
- Прошлое ≠ будущее. Бэктест показывает характер стратегии, а не пророчество.
- Симуляция по свечам чуть оптимистичнее реальности (проскальзывания,
  частичные исполнения). Реальный результат будет немного хуже.
- Sweep-чемпион почти всегда «подогнан» под конкретный отрезок — поэтому
  правило разных отрезков из пункта 1 обязательно.
