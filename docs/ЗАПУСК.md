# 🚀 Cloud-5 — Запуск и эксплуатация донат-бота

Подробная инструкция: установка, настройка, запуск 24/7 и решение проблем.
Бот принимает донаты в **Telegram Stars (⭐)**, благодарит спонсора и публикует
его **карточку с ником** на «Доске почёта» (в группе или канале).

---

## 📦 Что внутри

| Возможность | Описание |
|---|---|
| Кнопки сумм | 100 / 200 / 300 / 400 и ТОП 1000 ⭐ (настраивается) |
| Оплата | Telegram Stars (валюта XTR), без платёжного провайдера |
| Карточка спонсора | PNG со случайным оформлением и ником донатера |
| Доска почёта | Автопубликация карточки в привязанную группу/канал |
| Тест без оплаты | Команда `/testdonate` (только для админа) |
| Мульти-бот | Один процесс держит несколько ботов (мульти-тенант) |

---

## 1. Требования

- **Python 3.11+**
- На телефоне — **Termux** (Android). На ПК/сервере — любой Linux/macOS/Windows.
- Для картинок-карточек — **Pillow** (опционально; без него шлётся текст).
- Токен бота от **@BotFather**.

---

## 2. Установка на телефон (Termux)

```bash
# 1. Поставить пакеты
pkg update -y && pkg upgrade -y
pkg install -y python git python-pillow

# 2. Получить код (или распаковать архив в ~/Cloud-5)
cd ~
git clone <repo-url> Cloud-5      # или: tar -xzf cloud5.tar.gz && mv cloud5 Cloud-5
cd Cloud-5

# 3. Виртуальное окружение и зависимости
python -m venv .venv
. .venv/bin/activate
pip install -e .

# 4. Конфиг
cp .env.termux.example .env
nano .env          # впиши DEFAULT_ADMIN_IDS = свой Telegram ID
```

> **Важно:** `python-pillow` ставится именно через `pkg`, а не через pip —
> так надёжнее на Android.

---

## 3. Установка на ПК / сервере

```bash
git clone <repo-url> Cloud-5 && cd Cloud-5
python -m venv .venv && . .venv/bin/activate
pip install -e ".[images]"        # с поддержкой картинок
cp .env.example .env
nano .env
```

---

## 4. Настройка `.env`

| Переменная | Значение для телефона | Назначение |
|---|---|---|
| `DATABASE_URL` | `sqlite+aiosqlite:///./cloud5.db` | База (SQLite — ничего ставить не надо) |
| `REDIS_URL` | *(пусто)* | Без Redis — состояния в памяти |
| `BOT_MODE` | `polling` | Режим для телефона |
| `DEFAULT_ADMIN_IDS` | `7164355388` | Твой Telegram ID — доступ к `/admin`, `/testdonate`, `/setwall` |
| `ANTHROPIC_API_KEY` | *(пусто)* | Нужен только для ИИ-модуля |

Свой Telegram ID можно узнать у бота **@userinfobot**.

---

## 5. Первый запуск (создание донат-бота)

```bash
. .venv/bin/activate

# 1. Создать таблицы БД
python -m cloud5.cli init-db

# 2. Добавить своего бота (токен от @BotFather)
python -m cloud5.cli add-tenant --title "Донат" --token 123456:ABC...

# 3. Перевести его в режим доната с нужными суммами
python -m cloud5.cli setup-donate --tenant-id 1 --amounts 100,200,300,400,1000

# 4. Запустить
bash scripts/termux-run.sh
```

После запуска отправь боту в личке **`/start`** — увидишь кнопки сумм.

---

## 6. Привязка «Доски почёта»

1. Создай **группу** (или канал) для витрины спонсоров.
2. Добавь туда своего бота и сделай его **администратором** с правом отправки
   сообщений.
3. В этой группе отправь команду:
   ```
   /setwall
   ```
   Бот ответит «✅ Доска почёта привязана к этому чату».

Теперь каждый донат автоматически публикует карточку спонсора в эту группу.

---

## 7. Тест без реальной оплаты

В личке бота (от имени админа) отправь:
```
/testdonate
```
Бот пришлёт карточку тебе **и** в группу-доску — звёзды при этом **не**
списываются. Команда доступна только админам.

---

## 8. Запуск 24/7

```bash
bash scripts/termux-run.sh
```
Скрипт:
- держит `wake-lock`, чтобы Android не усыплял процесс;
- автоматически перезапускает бота, если он упал.

Останов — `Ctrl+C`.

> Чтобы Termux не убивался системой: отключи оптимизацию батареи для Termux в
> настройках Android и держи установленным приложение **Termux:API**.

---

## 9. Справочник CLI

```bash
python -m cloud5.cli <команда> [опции]
```

| Команда | Назначение |
|---|---|
| `init-db` | создать таблицы базы |
| `quickstart` | всё за раз: БД + тестовый бот + демо-данные |
| `add-tenant --title T --token TOKEN [--modules ...]` | добавить бота |
| `list-tenants` | список ботов и их `id` |
| `setup-donate --tenant-id N --amounts 100,200,1000` | режим доната |
| `enable-module --tenant-id N --module M` | включить модуль |
| `add-admin --tenant-id N --telegram-id ID` | назначить админа конкретного бота |
| `seed` | демо-данные для показа |

Доступные модули: `donate`, `shop`, `booking`, `support`, `ai_assistant`.

---

## 10. Управление из бота (`/admin`)

Команда **`/admin`** (только для админа) открывает панель:
- 💝 **Донат** → изменить суммы кнопок (через запятую), посмотреть статус доски.
- Управление товарами/услугами/тикетами — если включены соответствующие модули.

После смены сумм отправь `/start`, чтобы меню обновилось.

## 11. Решение проблем

**«Sorry, but this payment method is not available for the selected product»**
— это ошибка **Telegram при покупке звёзд**, не бота. У плательщика 0 ⭐, а купить
их выбранным способом нельзя (часто — региональное ограничение). Решение: купить
звёзды через Google Play / Fragment, либо пусть донатит тот, у кого ⭐ уже есть.
Сам бот счёт выставляет корректно.

**Пришёл текст вместо картинки** — не установлен Pillow.
Поставь: `pkg install python-pillow` (телефон) или `pip install pillow` (ПК).

**Кириллица в карточке не рисуется** — шрифт лежит в
`src/cloud5/assets/fonts/DejaVuSans-Bold.ttf` и идёт в комплекте; проверь, что
папка `assets/fonts` на месте.

**`/testdonate` молчит** — твой Telegram ID не в `DEFAULT_ADMIN_IDS`. Впиши в
`.env` и перезапусти.

**Меню не обновилось после смены сумм** — отправь боту `/start`.

**Бот не видит изменений после `setup-donate`** — список модулей читается при
старте. Останови бота (`Ctrl+C`), выполни команду, затем запусти снова.

## 12. Структура проекта

```
Cloud-5/
├─ src/cloud5/
│  ├─ bot/main.py          # точка входа (polling)
│  ├─ cli.py               # команды управления
│  ├─ core/                # меню, реестр тенантов, middlewares, фильтры
│  ├─ modules/             # donate, shop, booking, support, ai, common, admin
│  ├─ services/            # card.py (картинки), payments, ai
│  ├─ db/                  # модели и сессии
│  └─ assets/fonts/        # шрифт DejaVu (кириллица для карточек)
├─ scripts/termux-run.sh   # запуск 24/7 на телефоне
├─ docs/                   # документация
├─ tests/                  # тесты (pytest)
├─ .env.termux.example     # пример конфига для телефона
└─ pyproject.toml          # зависимости
```
