================================================================
 ДОНАТ-БОТ НА ЗВЁЗДАХ — ИНСТРУКЦИЯ ДЛЯ TERMUX (Android)
================================================================

Бот показывает кнопки сумм (100/200/300/400 и ТОП 1000 звёзд),
принимает донаты в Telegram Stars, благодарит спонсора и публикует
его карточку с ником на «Доске почёта» (в группе или канале).


----------------------------------------------------------------
1. УСТАНОВКА
----------------------------------------------------------------

Открой Termux и выполни по очереди:

    pkg update -y && pkg upgrade -y
    pkg install -y python git python-pillow

    cd ~
    # распакуй архив сюда (или склонируй репозиторий) так, чтобы
    # появилась папка ~/Cloud-5
    tar -xzf cloud5-donate-bot.tar.gz        # если у тебя архив
    cd Cloud-5

    python -m venv .venv
    . .venv/bin/activate
    pip install -e .

ВАЖНО: python-pillow ставится через pkg (не через pip) — так надёжнее.
Без него бот всё равно работает, но шлёт текст вместо картинки.


----------------------------------------------------------------
2. НАСТРОЙКА (.env)
----------------------------------------------------------------

    cp .env.termux.example .env
    nano .env

В файле впиши свой Telegram ID в строку:

    DEFAULT_ADMIN_IDS=ТВОЙ_ID

Свой ID можно узнать у бота @userinfobot.
Сохранить в nano: Ctrl+O, Enter, затем выйти: Ctrl+X.


----------------------------------------------------------------
3. ПЕРВЫЙ ЗАПУСК (создание бота)
----------------------------------------------------------------

Получи токен бота у @BotFather, затем:

    . .venv/bin/activate
    python -m cloud5.cli init-db
    python -m cloud5.cli add-tenant --title "Донат" --token 123456:ABC...
    python -m cloud5.cli setup-donate --tenant-id 1 --amounts 100,200,300,400,1000

Запуск:

    bash scripts/termux-run.sh

В личке бота отправь /start — появятся кнопки сумм.


----------------------------------------------------------------
4. ДОСКА ПОЧЁТА (группа со спонсорами)
----------------------------------------------------------------

1) Создай группу (или канал) для витрины спонсоров.
2) Добавь туда своего бота и сделай его АДМИНИСТРАТОРОМ
   с правом отправлять сообщения.
3) В этой группе отправь команду:

       /setwall

   Бот ответит «Доска почёта привязана к этому чату».

Теперь каждый донат автоматически постит карточку спонсора в группу.


----------------------------------------------------------------
5. ТЕСТ БЕЗ ОПЛАТЫ
----------------------------------------------------------------

В личке бота (от своего имени, ты админ) отправь:

    /testdonate

Бот пришлёт карточку тебе И в группу-доску. Звёзды НЕ списываются.


----------------------------------------------------------------
6. ЗАПУСК 24/7
----------------------------------------------------------------

    bash scripts/termux-run.sh

Скрипт держит wake-lock и перезапускает бота при падении.
Останов — Ctrl+C.

Чтобы Android не убивал Termux: отключи оптимизацию батареи
для Termux в настройках телефона.


----------------------------------------------------------------
7. КОМАНДЫ CLI
----------------------------------------------------------------

  python -m cloud5.cli init-db
        создать таблицы базы

  python -m cloud5.cli add-tenant --title T --token TOKEN
        добавить бота (сразу в режиме доната)

  python -m cloud5.cli list-tenants
        список ботов и их id

  python -m cloud5.cli setup-donate --tenant-id N --amounts 100,200,1000
        задать кнопки сумм

  python -m cloud5.cli add-admin --tenant-id N --telegram-id ID
        назначить дополнительного админа


----------------------------------------------------------------
8. УПРАВЛЕНИЕ ИЗ БОТА
----------------------------------------------------------------

  /start       — показать кнопки доната
  /admin       — панель (суммы кнопок, статистика)   [только админ]
  /testdonate  — тест карточки без оплаты            [только админ]
  /setwall     — привязать Доску почёта (в группе)   [только админ]
  /unsetwall   — отвязать Доску почёта               [только админ]

После смены сумм отправь боту /start, чтобы меню обновилось.


----------------------------------------------------------------
9. ЧАСТЫЕ ВОПРОСЫ
----------------------------------------------------------------

«Sorry, but this payment method is not available...»
    Это ошибка Telegram при ПОКУПКЕ звёзд (у плательщика 0 ⭐),
    а не бота. Купить звёзды нужно через Google Play/Fragment,
    либо пусть донатит тот, у кого звёзды уже есть.

Пришёл текст вместо картинки
    Не установлен Pillow:  pkg install python-pillow

/testdonate молчит
    Твой Telegram ID не вписан в DEFAULT_ADMIN_IDS в .env.

Меню не обновилось после смены сумм
    Отправь боту /start.

Бот не видит изменений после setup-donate
    Останови бота (Ctrl+C), выполни команду, потом запусти снова.


----------------------------------------------------------------
10. СТРУКТУРА
----------------------------------------------------------------

  src/cloud5/
    bot/main.py        — точка входа (polling)
    cli.py             — команды управления
    core/              — меню, реестр ботов, middlewares, фильтры
    modules/           — donate, common, admin
    services/card.py   — генерация картинок-карточек
    db/                — модели и сессии
    assets/fonts/      — шрифт DejaVu (кириллица для карточек)
  scripts/termux-run.sh — запуск 24/7
  .env.termux.example   — пример конфига
